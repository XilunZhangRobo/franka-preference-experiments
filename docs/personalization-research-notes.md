# Follow-up ideas for preference memory

## A task that Matt lets the robot finish

Matt proposed this as a hypothesis for the note-writing study. When the robot completes a task and Matt leaves its work in place, the absence of an intervention may weakly inform an ambiguity in an existing preference file. Silence alone provides too little evidence to open a new file.

For example, an existing note might say that Matt has moved certain papers away from drinks, with uncertainty about which papers matter. If he watches the robot carry a drink past an ordinary print and leaves it there, the episode could count as weak evidence about the scope of that note. He could also have been distracted, missed the crossing, or chosen to let it go. A later explicit correction should carry more weight.

For a future test, compare the same visible action when Matt has an opportunity to respond and when his attention is elsewhere. Record what the camera actually shows, the uncertainty before and after, and whether repeated observations make a better prediction on a new task. Preserve an option to leave the note alone. The fixed-question study uses its original protocol.
