# Exploratory shuffled-note control

This additional comparison was specified after the cold, observation, and correct-note agents had replied, and before the control agent saw any inputs. It asks whether providing the correct personal evidence accounts for the gain over cold start, or whether giving the agent any plausible written personal context is enough.

Use the locked decision scenes and protocol. Rotate the ten note bodies by three places in the stable family order Q, R, H, O, M, F, C, D, L, S. Give the fresh decision agent all ten note bodies under the new headings. Preserve the original note text, including original person letters where they occur. The agent sees no mapping table, correctly matched notes, or preference labels. The exact same frozen grading key applies. Report the control separately as an exploratory comparison. An unrelated note may be ignored, so this tests irrelevant context and does not test conflicting credible evidence about the same task.
