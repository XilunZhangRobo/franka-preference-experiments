# Qualification protocol

Count a family when both fresh cold agents miss at least one of the same main probes and both fresh note-only agents choose the private target on that probe. Both note-only agents must also meet every scored exception in the family. Other main probes test breadth of transfer. Record every trial and any candidate that falls short. A reliable miss here means a repeated mismatch with one simulated person's target within this benchmark.

The first pass and counterbalanced pass use identical actions in different trial order and reverse the A/B labels. Both passes use fresh independent decision agents per condition. Cold agents see only the decision scenes. Note-only agents see the same scenes and only the agent-authored notes for personal context. Trial letters identify independent users. The assessor compares the choices with a private key locked before the trial decisions. The earlier seven qualifying families are scored by the same rule from their recorded passes.

P and D replace the ceiling cases from the earlier suite with more discriminating tasks. L repeats the matched lighting scenes with the overhead-preferring user. S is a reserve task family. If more than three qualify, keep P, D, and L in the ten-task set and report S separately.
